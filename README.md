# 中国特色城市 · 城市印象志

一个使用 Vue 3 + Vite 构建的纯静态网站，用于展示中国特色城市的风貌：每座城市的特色、饮食、文化、历史与当地习惯。

## 技术栈

- Vue 3（组合式 API）
- Vue Router（hash 路由，静态部署零配置）
- Vite 6
- 无 UI 框架，手写中式风格样式

## 内容来源

站点数据全部来自 `docs/` 目录下的 Markdown 文件，每个省份一个文件，构建时自动解析，无需改动代码即可增删内容。

文件格式约定：

```md
# 江苏

江苏地处长江三角洲……（省份简介）

## 南京

- **特色**：六朝古都、十朝都会……
- **饮食**：盐水鸭、鸭血粉丝汤……
- **文化**：明城墙、夫子庙……
- **历史**：东吴建都……
- **当地习惯**：生活从容……
```

直辖市（北京、上海、天津）可以额外使用 `## 全市概览` 和 `## 主要区域` 小节，站点会以概览卡片和区域列表展示。

## 本地开发

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

构建产物输出到 `dist/`，站点使用相对路径（`base: './'`）与 hash 路由，可以直接把 `dist/` 部署到任意静态托管（GitHub Pages、Nginx、对象存储等），无需额外配置。

## 项目结构

```text
docs/                  省份 Markdown 内容源
src/
  data/                内容解析与搜索（parseDocs、store）
  components/          页头、页脚、搜索框、省份卡、城市卡
  views/               首页、省份列表、省份详情、404
  styles/main.css      全局样式
scripts/qa.mjs         无头浏览器渲染自检脚本
```

## 补充内容

在 `docs/` 下新建 `省份名.md` 并遵循上文格式，重新 `npm run build` 后即可在站点中看到新省份。图片引用（`![名称](路径)`）会被自动忽略，不会显示在页面上。
