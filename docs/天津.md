# 天津

天津是渤海之滨的直辖市，九河下梢、拱卫京畿，以中西合璧的近代建筑和浓郁的市井曲艺文化闻名。

## 全市概览

- **特色**：海河穿城而过，五大道万国建筑博览与古文化街的津味民俗并存，是近代中国北方开埠城市的缩影。
- **饮食**：狗不理包子、十八街麻花、耳朵眼炸糕、煎饼果子、锅巴菜、罾蹦鲤鱼，以及渤海海鲜。
- **文化**：相声发祥地之一，天津快板、杨柳青年画、泥人张彩塑，海河两岸的码头与曲艺市井文化底蕴深厚。
- **历史**：明永乐二年设卫筑城，1860年开埠后成为北方最大工商业城市，洋楼街巷记录着百年风云。
- **当地习惯**：天津人热情幽默，爱说“嘛”字口头禅，懂吃会玩、乐观恋家，市井烟火气浓。

## 主要区域

- **和平区**：五大道、小白楼、劝业场，近代洋楼与商业核心。
- **河北区**：天津之眼、意式风情区，海河景观精华段。
- **河西区**：文化中心与梅江居住区。
- **南开区**：天津大学、南开大学所在，老城厢与鼓楼文化。
- **滨海新区**：天津港、泰达与自贸区，北方对外开放门户。
- **环城与远郊**：西青杨柳青古镇、武清佛罗伦萨小镇、蓟州盘山与独乐寺等。
