# 云南

云南地处中国西南边陲，横断山脉与云贵高原在此交汇，多民族聚居、四季如春，是自然风光与民族风情最丰富的省份之一。

## 昆明

- **特色**：春城，云南省会，四季如春的高原花都。
- **饮食**：过桥米线、汽锅鸡、烧饵块、鲜花饼、野生菌火锅。
- **文化**：滇池、石林、翠湖海鸥，彝族火把节与多民族文化交融。
- **历史**：战国时滇国故地，元代设云南行省，昆明为省会延续至今。
- **当地习惯**：生活从容，讲究吃米线，冬日翠湖喂海鸥是市民日常。

## 大理

- **特色**：风花雪月之城，苍山洱海间的高原古城。
- **饮食**：乳扇、喜洲粑粑、砂锅鱼、雕梅。
- **文化**：白族民居与扎染、三月街、本主文化，茶马古道重镇。
- **历史**：唐代南诏、宋代大理国都城，五百年国都史。
- **当地习惯**：慢生活盛行，环洱海骑行与古城晒太阳是日常。

## 丽江

- **特色**：世界文化遗产丽江古城，纳西族东巴文化之乡。
- **饮食**：丽江粑粑、鸡豆凉粉、腊排骨火锅、纳西烤肉。
- **文化**：东巴文字与东巴经、纳西古乐、玉龙雪山下的古城水巷。
- **历史**：宋末元初建城，明清茶马古道重镇，纳西族木氏土司治地。
- **当地习惯**：古城临水而居，客栈文化兴盛，火塘与打跳融入节庆。

## 西双版纳

- **特色**：热带雨林与傣族风情，孔雀之乡。
- **饮食**：菠萝紫米饭、香茅草烤鱼、傣味撒撇、热带水果。
- **文化**：泼水节、贝叶经、傣族织锦，南传佛教文化浓郁。
- **历史**：古称勐泐，傣族先民聚居地，1953年成立西双版纳傣族自治州。
- **当地习惯**：四季如夏，赶摆、泼水、过赕等民俗热闹，生活节奏松弛。

## 香格里拉

- **特色**：世外桃源，滇西北高原藏地风光。
- **饮食**：酥油茶、青稞饼、牦牛肉火锅、糌粑。
- **文化**：藏传佛教文化、独克宗古城、梅里雪山朝圣文化。
- **历史**：民国时曾设中甸县，因《消失的地平线》得名香格里拉，2001年更名。
- **当地习惯**：藏地节庆浓厚，转经与锅庄舞融入日常。
