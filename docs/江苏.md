# 江苏

江苏地处长江三角洲，跨江滨海，经济发达、文教昌盛，是吴文化、金陵文化与运河文化的交汇之地。

## 南京

- **特色**：六朝古都、十朝都会，江苏省会，山水城林一体。
- **饮食**：盐水鸭、鸭血粉丝汤、牛肉锅贴、桂花糖芋苗、美龄粥。
- **文化**：明城墙、夫子庙、云锦、金陵刻经，梧桐与民国建筑遍布。
- **历史**：东吴建都，六朝烟水，明初为京师，近代曾为民国首都。
- **当地习惯**：生活从容，四季爱吃鸭，梧桐树下散步、老城南吃早是日常。

## 无锡

- **特色**：太湖明珠，近代民族工商业发祥地之一。
- **饮食**：无锡酱排骨、甜口小笼、油面筋、太湖三白。
- **文化**：惠山泥人、锡剧、吴文化发源，太湖渔文化。
- **历史**：吴太伯奔吴之地，明清以来工商繁盛，近代实业家辈出。
- **当地习惯**：精致细腻，口味偏甜，讲究生活品质。

## 徐州

- **特色**：五省通衢，两汉文化看徐州。
- **饮食**：地锅鸡、羊肉汤、烙馍卷馓子、把子肉。
- **文化**：汉墓、汉画像石、汉兵马俑，徐州梆子与彭祖文化。
- **历史**：古彭城，楚汉相争与淮海战役重要战场。
- **当地习惯**：南北过渡民风，豪爽好客，爱吃羊肉。

## 常州

- **特色**：龙城，长三角智造名城。
- **饮食**：银丝面、天目湖鱼头、大麻糕、常州萝卜干。
- **文化**：春秋淹城遗址、天宁寺、乱针绣。
- **历史**：淹城为春秋古城遗存，近代民族工业与实业教育兴盛。
- **当地习惯**：务实精明，生活安逸，公园与运河边休闲普遍。

## 苏州

- **特色**：人间天堂、园林之城，古典与现代并存的江南典范。
- **饮食**：松鼠桂鱼、苏式汤面、阳澄湖大闸蟹、藏书羊肉、苏式糕点。
- **文化**：昆曲、评弹、古典园林、刺绣缂丝，吴侬软语。
- **历史**：春秋吴国都城，明清江南经济文化中心，千年古城格局犹存。
- **当地习惯**：精致讲究，听评弹、喝早茶、游园林，节奏温润。

## 南通

- **特色**：江海门户，“中国近代第一城”。
- **饮食**：河豚、文蛤、蟹黄包、脆饼。
- **文化**：张謇实业教育文化、濠河景观、蓝印花布。
- **历史**：清末张謇在此兴实业、办教育，开创中国近代城市典范。
- **当地习惯**：务实重教，敢于尝鲜（吃河豚习俗讲究）。

## 连云港

- **特色**：西游记文化名城、东方大港，花果山所在地。
- **饮食**：海鲜、凤鹅、凉粉、云雾茶。
- **文化**：西游文化、东海水晶文化、徐福东渡传说。
- **历史**：秦设朐县，秦汉时徐福传说与海上交通于此展开。
- **当地习惯**：港口城市靠海吃海，朴实爽快。

## 淮安

- **特色**：运河之都、淮扬菜发源地，周恩来故乡。
- **饮食**：软兜长鱼、平桥豆腐、茶馓、文楼汤包、开洋蒲菜。
- **文化**：运河文化、淮剧、名人文化，运河漕运遗产丰富。
- **历史**：明清漕运总督驻地，淮扬菜由此闻名天下。
- **当地习惯**：讲究吃，早茶文化浓，生活从容。

## 盐城

- **特色**：湿地之都，丹顶鹤与麋鹿的栖息家园。
- **饮食**：盐城八大碗、东台鱼汤面、建湖藕粉圆子、阜宁大糕。
- **文化**：淮剧、湿地生态文化、海盐文化。
- **历史**：西汉设盐渎县，两千余年煮海为盐的历史。
- **当地习惯**：朴实厚道，生态意识强，滩涂湿地四季皆景。

## 扬州

- **特色**：烟花三月下扬州，园林与早茶并称的城市。
- **饮食**：扬州炒饭、狮子头、三头宴、烫干丝、早茶点心。
- **文化**：个园何园、扬州八怪、漆器玉器、广陵琴派。
- **历史**：春秋建邗城，隋唐大运河枢纽，清代盐商云集。
- **当地习惯**：早上皮包水、晚上水包皮，慢生活讲究惬意。

## 镇江

- **特色**：城市山林、天下第一江山，长江与运河交汇处。
- **饮食**：锅盖面、水晶肴肉、镇江香醋。
- **文化**：金山寺、西津渡、《白蛇传》传说，茅山道教文化。
- **历史**：三国京口，东晋南朝为军事重镇，近代开埠。
- **当地习惯**：悠闲恋家，吃面配香醋是刻进日常的习惯。

## 泰州

- **特色**：水城慢生活，人民海军诞生地。
- **饮食**：泰州干丝、黄桥烧饼、溱湖八鲜、鱼汤面。
- **文化**：梅兰芳故里、溱潼会船节、早茶文化。
- **历史**：南唐置泰州，1949年人民海军在白马庙诞生。
- **当地习惯**：重视早茶，生活节奏舒缓，水乡气息浓。

## 宿迁

- **特色**：项王故里、酒都，西楚文化名城。
- **饮食**：洋河大曲、骆马湖鱼鲜、黄狗猪头肉、山楂糕。
- **文化**：项羽文化、酒文化、乾隆行宫。
- **历史**：秦置下相县，项羽故乡，清代乾隆南巡驻跸。
- **当地习惯**：豪爽爱酒，待人热忱。
