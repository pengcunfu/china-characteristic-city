# 西藏

西藏位于青藏高原腹地，平均海拔四千米以上，雪山、圣湖与寺庙构成了世界屋脊的独特景观，藏文化底蕴深厚。

## 拉萨

- **特色**：日光城，雪域高原的首府与朝圣中心。
- **饮食**：甜茶、酥油茶、藏面、牦牛肉、糌粑。
- **文化**：布达拉宫、大昭寺、八廓街转经，藏历新年与雪顿节。
- **历史**：松赞干布迁都拉萨，文成公主入藏，千年政教中心。
- **当地习惯**：转经、煨桑融入日常，茶馆甜茶是社交场所。

## 日喀则

- **特色**：西藏第二大城市，后藏文化中心。
- **饮食**：酥油茶、青稞酒、藏式包子、牦牛酸奶。
- **文化**：扎什伦布寺、珠穆朗玛峰登山文化、后藏歌舞。
- **历史**：班禅驻锡地，历代班禅大师驻跸于此。
- **当地习惯**：敬山敬佛，珠峰脚下的节庆庄重热烈。

## 林芝

- **特色**：西藏江南，尼洋河谷的绿色宝地。
- **饮食**：石锅鸡、藏香猪、青稞饼、高原水果。
- **文化**：雅鲁藏布大峡谷、南迦巴瓦峰、桃花节。
- **历史**：工布地区古已有之，1959年后设林芝专区，2015年撤地设市。
- **当地习惯**：气候温和，生活安逸，桃花节与工布新年热闹。

## 昌都

- **特色**：藏东门户，三江并流地带的咽喉。
- **饮食**：昌都藏面、酥油茶、牦牛肉干、青稞糌粑。
- **文化**：强巴林寺、康巴文化、锅庄与热巴舞。
- **历史**：茶马古道重要节点，康巴藏区历史重镇。
- **当地习惯**：康巴人豪放热情，歌舞与节庆氛围浓烈。

## 那曲

- **特色**：世界屋脊的屋脊，羌塘草原腹地。
- **饮食**：风干牦牛肉、酥油茶、糌粑、酸奶。
- **文化**：赛马节、羌塘草原游牧文化、高原湖泊景观。
- **历史**：清代设那曲宗，1959年建那曲专区，游牧历史延续千年。
- **当地习惯**：逐水草而居的游牧生活，赛马会是一年盛事。
