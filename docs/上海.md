# 上海

上海是直辖市，国际经济、金融、贸易、航运和科技创新中心，也是中西文化交融最深的“魔都”。

## 全市概览

- **特色**：外滩万国建筑与陆家嘴摩天楼隔江相望，石库门里弄与咖啡馆并存，精致与市井同在。
- **饮食**：本帮红烧肉、油爆虾、小笼包、生煎、排骨年糕、葱油拌面、蝴蝶酥。
- **文化**：海派文化，旗袍、沪剧、石库门、话剧电影、咖啡馆与梧桐街区文化。
- **历史**：元代设上海县，1843年开埠，租界时期成为远东金融中心，1949年后发展为全国经济龙头。
- **当地习惯**：精明守约、讲究分寸，生活精致，咖啡与市井早点并重。

## 主要区域

- **黄浦**：外滩、南京路、豫园，城市名片所在。
- **徐汇**：衡复风貌区与武康路，梧桐区的文艺慢生活。
- **静安**：南京西路商圈，时尚消费中心。
- **浦东**：陆家嘴、张江、临港，改革开放前沿。
- **虹口、杨浦**：北外滩与大学路，文化创意聚集。
- **闵行、宝山**：虹桥枢纽与邮轮母港。
- **嘉定、松江、青浦**：汽车城、大学城、进博会与江南古镇。
- **奉贤、金山、崇明**：生态海岸与田园海岛。
