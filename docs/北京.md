# 北京

北京是中华人民共和国的首都，全国政治、文化、国际交往和科技创新中心，拥有三千多年建城史、八百多年建都史，是传统与现代交融最典型的中国城市。

## 全市概览

- **特色**：红墙黄瓦与摩天楼并存，胡同四合院与中关村科技园同在，故宫、长城等世界遗产和全国最密集的文博资源聚集于此。
- **饮食**：北京烤鸭、铜锅涮肉、炸酱面、卤煮火烧、爆肚、豆汁儿焦圈、炒肝，以及驴打滚、豌豆黄等京味小吃。
- **文化**：京剧发祥地，相声、评书、庙会文化兴盛；故宫、天坛、颐和园、长城等文化遗产塑造了厚重的京味文化。
- **历史**：燕蓟故地，辽为南京、金为中都，元明清三代定都于此，1949年成为新中国首都，是数百年国运所系之城。
- **当地习惯**：讲礼数、重规矩，“您”字常挂嘴边；爱遛弯儿、下棋、听戏，既有皇城根下的大气，也有市井烟火气。

## 主要城区

- **东城、西城**：老城核心，故宫、前门、什刹海、天坛所在，胡同与老字号最集中。
- **朝阳**：CBD、使馆区与演艺中心，时尚消费和高品质生活聚集地。
- **海淀**：中关村与高校云集，全国科技教育高地。
- **丰台**：北京南站与丽泽商务区，城南门户。
- **石景山、门头沟**：首钢园转型与西山永定河山水带。
- **通州**：北京城市副中心，行政办公与文化设施集中。
- **昌平、顺义、大兴**：科技园区、首都机场与临空经济区。
- **房山、怀柔、密云、延庆、平谷**：山水生态与文旅休闲区，延庆为冬奥赛区。
