# 陕西

陕西位于中国地理版图中心，黄土高原与秦岭在此分野，十三朝古都西安承载着中华文明最厚重的记忆。

## 西安

- **特色**：十三朝古都，世界历史名城，陕西省会。
- **饮食**：肉夹馍、羊肉泡馍、凉皮、biangbiang面、葫芦鸡。
- **文化**：兵马俑、大雁塔、城墙、碑林，唐诗与秦腔的故乡。
- **历史**：周秦汉唐等十三朝建都于此，古丝绸之路起点。
- **当地习惯**：晨起一碗泡馍，城墙根下听秦腔，历史感融进日常。

## 咸阳

- **特色**：中国第一帝都，秦汉文化核心区。
- **饮食**：biangbiang面、锅盔、泾阳茯茶、礼泉烙面。
- **文化**：乾陵、茂陵、汉阳陵，秦都咸阳宫遗址。
- **历史**：秦孝公迁都于此，秦始皇统一六国后成为帝国都城。
- **当地习惯**：关中民风质朴，面食为主，讲究实在。

## 宝鸡

- **特色**：炎帝故里、青铜器之乡，关中西部重镇。
- **饮食**：岐山臊子面、擀面皮、豆花泡馍、西府小吃。
- **文化**：法门寺、青铜器博物院、西府社火与秦腔。
- **历史**：周秦文明发祥地，陈仓古地，诸葛亮五丈原所在。
- **当地习惯**：爱吃面、唱秦腔，春节社火热闹非凡。

## 延安

- **特色**：革命圣地，黄土高原上的红色之城。
- **饮食**：洋芋擦擦、延安小米粥、陕北大烩菜、荞面饸饹。
- **文化**：宝塔山、杨家岭、枣园，延安精神与陕北民歌、安塞腰鼓。
- **历史**：1935年至1948年中共中央所在地，中国革命转折之地。
- **当地习惯**：红色记忆融入日常，秧歌腰鼓逢节必闹。

## 汉中

- **特色**：汉家发祥地，秦巴之间的小江南。
- **饮食**：汉中面皮、菜豆腐、浆水面、褒河鲜鱼。
- **文化**：汉台、张良庙、武侯祠，三国文化遗存密集。
- **历史**：刘邦在此发迹建立汉朝，汉文化由此得名。
- **当地习惯**：四季分明、生活安逸，米面皆宜、喜食酸辣。

## 榆林

- **特色**：塞上名城，陕北能源重镇。
- **饮食**：羊肉面、拼三鲜、陕北黄米馍馍、子洲馃馅。
- **文化**：镇北台、红石峡、统万城，长城与边塞文化。
- **历史**：秦汉设上郡，明长城九边重镇之一，近代为革命老区。
- **当地习惯**：豪爽大气，陕北民歌与腰鼓是节庆标配。
